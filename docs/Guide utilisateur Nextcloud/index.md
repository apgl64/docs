## 1. Présentation et Connexion

Nextcloud est l'outil institutionnel de l'APGL 64 pour le stockage cloud et le partage collaboratif.

- **Accès web** : `https://cloud.apgl64.fr`
- **Authentification** : Identifiants de votre compte de domaine APGL.

---

## 2. Gestion des Fichiers et Dossiers

Vous pouvez organiser vos dossiers par projets et synchroniser vos fichiers locaux via le client officiel Nextcloud Desktop.

---

## 3. Partage Sécurisé & Liens Externe

- **Partage interne** : Saisissez le nom d'un agent pour lui accorder les droits d'accès ou de modification.
- **Lien public sécurisé** : Définissez obligatoirement un mot de passe et une date d'expiration pour tout partage vers un destinataire externe.
